# 차량 피하기 게임

## 프로젝트 소개

Unity 6을 이용하여 제작한 차량 피하기 게임입니다.

플레이어는 도로를 이동하며 차량을 피해야 하고, 60초 동안 생존하면 클리어됩니다.

---

## 조작 방법

W : 위 이동

A : 왼쪽 이동

S : 아래 이동

D : 오른쪽 이동

---

## 게임 규칙

* 플레이어 목숨은 3개입니다.
* 차량과 충돌 시 목숨이 1 감소합니다.
* 목숨이 모두 소진되면 게임 오버가 됩니다.
* 60초 동안 생존하면 게임 클리어가 됩니다.

---

## 구현 기능

### 플레이어 이동

* CharacterController를 사용하여 이동 구현

### 차량 시스템

* 차량 자동 이동
* 화면 끝 도달 시 반대편에서 재등장
* 차량별 속도 차이 적용

### 충돌 시스템

* Trigger 충돌 감지
* 충돌 시 목숨 감소

### UI

* 남은 목숨 표시
* 남은 시간 표시

### 게임 오버

* 목숨 0일 때 게임 정지

### 게임 클리어

* 60초 생존 시 게임 정지

---
